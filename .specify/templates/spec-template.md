- **A11Y-001**: All new interactive elements MUST be keyboard-navigable and have visible focus indicators.
- **A11Y-002**: Colour contrast in light and dark themes MUST meet WCAG 2.1 AA (≥ 4.5:1 for normal text).
- **A11Y-003**: New components MUST respect `prefers-reduced-motion`.
- **A11Y-004**: Automated axe-core checks MUST pass for all new pages/components.
- **I18N-001**: All user-facing strings introduced by this feature MUST be externalised to locale files (ar, fr, en).
- **I18N-002**: If the feature adds UI layout: RTL behaviour for Arabic MUST be verified and tested.
- **I18N-003**: Any AI-generated text (agent status lines, error messages) MUST respect the user's selected interface language.
